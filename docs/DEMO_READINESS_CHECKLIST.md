## Быстрый старт для демо

### Вариант A — только фронтенд (рекомендуется, нет зависимостей)

```bash
cd frontend/apps/web
npm run dev
# → http://localhost:5173
```

Данные: встроенный demo-набор (7 сделок, 5 задач, 4 пользователя).  
Никаких внешних зависимостей. Не нужен сервер.

### Вариант B — полный стек с реальной базой (для полного функционала)

```bash
# 1. Создать директорию для БД
mkdir -p data

# 2. Применить схему
npm run db:migrate

# 3. Засеять демо-данные
npm run db:seed

# 4. Запустить фронт + бэк
npm run dev
# → frontend: http://localhost:5173
# → backend:  http://localhost:3000
```

Данные: реальные записи в SQLite — сделки, задачи, чаты, заметки, звонки.

## Что работает в ограниченном режиме (intentional)

| Функция | Статус | Сообщение для клиента |
|---------|--------|-----------------------|
| Кнопка «Позвонить» | tel: fallback | Открывает звонок через телефон — onlinePBX подключается после настройки |
| Отправка WhatsApp | dry-run / предупреждение | «Сообщение сохранено» — реальная отправка после настройки WAPPI |
| Фильтр аналитики по периоду | toast | «Фильтр будет доступен в следующей версии» |
| Создание новой сделки | toast | «Форма будет активирована после финальной настройки» |
| Уведомления (колокольчик) | toast | «Центр уведомлений будет активирован...» |
| Кнопка «Импорт AmoCRM» | toast | «Импорт будет запущен после финальной настройки» |
| Права доступа в Настройках | toast | «Управление правами будет доступно...» |
| Мобильное меню | toast | Sidebar активен на десктопе |

---

## Что НЕ нажимать во время демо

- ❌ **«Запустить импорт»** — AmoCRM импорт не настроен (покажет toast)
- ❌ **«Чаты»** в sidebar — страница заглушка (не crashes, но пустая)
- ❌ Телефония **«Настроить»** — если onlinePBX не настроен, покажет форму без данных
- ❌ Мобильное меню (кнопка сверху слева) — не реализовано на mobile

## Известные ограничения

1. **onlinePBX** — интеграция реализована на уровне кода, но не активна. Нужны реальные `ONLINEPBX_DOMAIN` и `ONLINEPBX_API_KEY`.
2. **WAPPI** — WhatsApp-диалог работает в dry-run режиме. Реальная отправка требует настройки WAPPI API.
3. **AmoCRM импорт** — CLI импорт реализован, но нужен экспорт из AmoCRM (`AMO_IMPORT_DB_PATH`).
4. **Аналитика** — таблицы реальные, графики-заглушки (визуальные плейсхолдеры).
5. **Мобильная версия** — адаптив частично, sidebar не скрывается на мобильных устройствах.
6. **Аутентификация** — простая (localStorage + hash), без JWT/сессий. Для production нужна замена.
